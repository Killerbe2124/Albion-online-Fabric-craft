# 🧵 Albion Online: Craft Calculator

## 📝 Описание
Инструмент для отслеживания и анализа крафта ткани (**Fabric**) в игре **Albion Online**. Страница позволяет вести учет истории продаж и просматривать базовую статистику, что помогает оптимизировать производственные процессы и максимизировать прибыль в игре.

## 🛠 Технологии
- **HTML5** – разметка и структура пользовательского интерфейса

## ⚙️ Функционал
- 📊 Отображение истории продаж крафтовых предметов.
- 📈 Подсчет и визуализация статистики (доходы, расходы, чистая прибыль).
- 🖥️ Простой и интуитивно понятный интерфейс, работающий прямо в браузере.
